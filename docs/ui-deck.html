Critical subsystem · Safety

Refuse & reframe

When a query tries to filter on a protected characteristic, Syft calmly declines that dimension, explains the stance, and still ranks on everything else. It must never error out or feel broken.

  • Warm inline note, not a red error
  • Shows exactly which dimensions it is ranking on
  • Results continue uninterrupted below
